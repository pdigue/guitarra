# IT-05 · F5.8 #3 y #4 · El aspecto: temas, iPad y Adivinar (`0.6.3`)

**Fecha:** 15/11/2026 · **Rama:** `auto/F5.8-aspecto` (PR #19) · **Requisitos:** V-10 y V-11 (nuevos); J-01, J-06, C-02, C-08, PL-03 y G-05 (modificados)

## Qué se hizo
- **Tres temas en Ajustes › Aspecto:** Madera (de fábrica, tu decisión del 15/11), Automático (claro u oscuro, como tu dispositivo) y Partitura. Se cambian cuando quieras y la elección se guarda.
- **Disposición para iPad y ordenador:** el mástil ya no se estira (en un iPad en vertical las cuerdas medían 150 px; ahora 67), y lo que sobra va al pentagrama y a la lectura. Las pestañas son un control segmentado, como en las apps de Apple.
- **Adivinar:** las pistas encendidas ocupan su franja, en grande; la nota que tocas, pequeña y en gris, para no confundirla con la que buscas.
- De paso, un fallo antiguo: en un iPad en horizontal el mástil de inicio dejaba los trastes en 38 px, por debajo de los 40 que pide el dedo.

## Por qué así
Antes, cada color estaba escrito «a mano» en decenas de reglas del CSS. Para tener tres temas habría que haber copiado el CSS tres veces. Ahora el CSS solo usa **variables** (las «fichas» de color), y cada tema solo cambia el valor de esas fichas.

## El concepto: variables de CSS y *media queries*
**1. Variables (propiedades personalizadas).** Se declaran una vez y se usan en todas partes:

```css
:root                       { --bg:#15100b; --text:#f4ece1; }   /* Madera */
html[data-theme="partitura"]{ --bg:#f5efe3; --text:#2b2118; }   /* Partitura */
body { background:var(--bg); color:var(--text); }
```

El JavaScript solo escribe `data-theme="partitura"` en `<html>` (función `aplicarTema()`), y el navegador vuelve a pintar todo con las fichas nuevas. Lo que está dentro del mástil redefine sus propias fichas (`.board { --text:… }`), porque el mástil es oscuro en todos los temas.

**2. Preguntar al dispositivo.** `matchMedia('(prefers-color-scheme: dark)')` dice si el sistema está en modo oscuro, y avisa si cambia: así «Automático» lo sigue con la app abierta. Si el navegador no sabe responder, la app elige oscuro y sigue funcionando (es la regla PL-04: detectar capacidades y tener alternativa).

**3. *Media queries* por tamaño.** `@media (min-width:700px) and (min-height:600px) { … }` aplica reglas solo en pantallas grandes. No se pregunta «¿es un iPad?», sino «¿cuánto sitio hay?», y así sirve también para cualquier tableta o ventana.
